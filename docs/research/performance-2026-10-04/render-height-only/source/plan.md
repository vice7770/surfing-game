## Source proof and callback count bounds

`SweptBarrel.ts:92-95` currently calls `sampleCubicSurface(...).height`. At `cubicSurface.ts:20-37`, each lookup creates two Catmull-Rom weight arrays, two derivative arrays and a result object, and evaluates height plus two unused slope sums. The candidate copies the literal coefficient arithmetic from `PhysicalSurfWater.ts:44-48`, keeps the original gx/gz/floor conversion, original nested j/i iteration, the identical clamped row/column/index expressions and `height += wz * wx * value` operation order. It returns the Number accumulator. There is no coordinate rounding, NaN replacement, validity filter, fround, changed zero-weight-node handling or alternative interpolation. In particular 0*NaN/Infinity is still evaluated. Typed numeric arrays and ordinary fixed `SurfaceGrid` values are the runtime contract; side-effecting property getters are not introduced as a new contract for this helper. The public old function remains untouched.

Deleted source work per callback: 32 derivative weighted accumulations, their 64 multiplies/32 additions, two derivative coefficient calculations, four temporary arrays (16 numeric elements total) and one result object (three fields). JavaScript may already scalar-replace some objects; allocation removal is a source fact, not a measured GC or FPS result.

For a complete ordinary drawing loft, height calls arise only from forwardRest (`sweptLoft.ts:869`), initial non-fully-lifted vertices (`:802`) and surviving end sealing (`:949`). With 128 profile points + 6 extension points and floor(40000/134)=298 slices, V<=39932. Initial and seal calls are each <=V. Thus N<=2V+restSamples<=79864+restSamples; restSamples is the actual forward-rest probe count, not the vertex count. Each active rest search has at most ceil(latest/0.5)+1 probes; latest is source/profile-dependent, so no independent fixed numerical rest bound is asserted. Survey/refinement does not call heightAt. Actual callback counts will be recorded during authorized frozen workload validation; none has been measured here.
