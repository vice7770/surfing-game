# Fixed SideFeed component-count cache: source and CPU evidence

The frozen candidate passed nine complete host-protocol cases and one bounded CPU mock-device cost gate. All 32 measured pairs favored the candidate. Mean complete-call saving was **0.868359 ms**, median **0.889604 ms**; AB and BA means were **0.884141 ms** and **0.852578 ms**. The stored report's approximate lower bound was **0.673676 ms**. This is the arithmetic normal bound `mean − 1.96 × sampleSD / √32` on one serial sample; it does not establish 95% coverage or a population result.

This archive contains source and CPU evidence only. It records no native trial, FPS result, runtime adoption, or main-branch merge. The canonical runtime authority for these gates is `b0e003b8670c9d0be83bc9bb24c30b5382a54499`. The original readiness file's source-only flags describe its earlier freeze, before root executed the later gates. ## Exact candidate and supported semantics

The [inert source transform](evidence/patch-source.mjs.txt) makes three substitutions in [GpuBoussinesq.ts](../../../../src/wave/gpu/GpuBoussinesq.ts): add a component-count field beside `feedSlots`, capture the count from the existing `writeFeed` shape refresh, and use it for the recurring time-block upload length. The ordinary packing phase otherwise scans all 116,000 public weights merely to retrieve that count. [SideFeed.ts](../../../../src/wave/SideFeed.ts) assigns the actual component count in its constructor and does not change it.

The supported claim concerns the real constructor-fixed `SideFeed` class. A monkey-patched or subclassed `deviceShape()` with dynamically changing components lies outside that claim. Exported `writeParams` remains literal original and still scans mutable slot counts per substep. Queue calls, payloads, byte lengths, order, clocks, arithmetic, feed/window/layout refreshes, no-feed and zero-slot branches are preserved. Public zero/restored weights without refresh retain the baseline's stale cached-slot/table behavior; the candidate does not repair that behavior. There is no per-substep shape cache.

The [proof source](evidence/proof.ts.txt), [mock-device source](evidence/mockGpu.ts.txt), [cost source](evidence/cost.ts.txt), and [bundling source](evidence/build.mjs.txt) are inert text. Baseline and candidate used their own actual canonical classes, preserving `instanceof` behavior. The bundles' four exact identities are retained in [compiled.json](evidence/compiled.json); the large generated runtime bundles are referenced by original aliases rather than duplicated. All 39 canonical imported runtime files are identified by their bytes/SHA256 and b0 Git blob in [manifest.json](manifest.json). The additional WebGPU type declaration and two package inputs also have b0 Git identities. Compiler and library pins are the recorded original input pins, not a claim that every transitive tool binary was pinned.

## Proof and cost outcomes

The [original proof report](evidence/proof-first/report.json) records nine passing cases: actual C1/C7/C64 feeds; public individual/all-zero/restored weights, generic uniforms, time/window/layout changes; fresh zero-slot/restoration; no-feed; deferred/multiple-substep commit, returned-field adoption and discard/rebase; map rejection and diagnostic no-readback; and the actual retained ordinary-size import. Ordered queue bytes or large-payload hashes, device-buffer bytes and lifecycle, nine CPU destinations and identities, clocks, plunge and CFL feedback matched literal baseline. Intermediate comparisons ran as assertions; the report retains case protocol hashes and event counts, not a full raw event trace. The sentinel feedback case tests host adoption, not a WGSL solution.

The [original cost report](evidence/cost-first/report.json) preserves all 32 raw total/stage samples. After eight fixed warm pairs, order was AB/BA/BA/AB repeated eight times, with 16 pairs per order. Mean baseline and candidate complete calls were **4.453737 ms** and **3.585378 ms**. Savings ranged from **0.002500 ms** to **2.566750 ms**. Every timed call used **one substep**; multiple-substep behavior was exercised only by the separate proof. The frozen useful-gain criterion required the heuristic lower bound and both order means to exceed 0.1 ms; this CPU gate passed. There were no adaptive extra pairs or retries.

The complete real `step(1/60)` / `runWaterStep` host path was timed: typed-array conversion, synchronous mock queue memory writes, original CFL, original uniforms/slot scans, encoder and dispatch bookkeeping, nine readback memory copies, asynchronous map microtask, unpacking, viscosity peak and plunge/clock adoption. Construction, intake, recording/hashing, equality comparisons and statistics were outside the timer. The mock uses no-op dispatches and small bookkeeping allocations; its memory writes and Promise microtasks do not reproduce real GPU execution, queue/driver stalls or map latency. Renderer, worker publication, post-water physics consumers and FPS were excluded. Imported fields did not evolve physically.

Root ran six strict/syntax/bundle/unarmed checks at 07:04:32–07:04:34 UTC, one 20-second-bounded proof at 07:05:07–07:05:10, then one 20-second-bounded cost at 07:05:36–07:05:38 on 2026-10-04. They exited zero with respectively 62, 67 and 69 pins unchanged. The [root wrappers](evidence/root-one.py.txt), [check terminal](evidence/root-checks/terminal.json), [proof terminal](evidence/root-proof-first/terminal.json), [cost terminal](evidence/root-cost-first/terminal.json), original commands, logs and pin arrays with unchanged outcomes are retained byte-exactly. [summary.json](summary.json) holds independently recomputed arithmetic from the stored rows.

## Actual input and its limits

The input was the separately committed F32 SET1 export from [live-big-capture](../../tube-stability-2026-10-04/live-big-capture/README.md): High/Rich Padang Big, seed 8761, C64, 160 × 725 = 116,000 cells. The original five-draw native capture failed after three actual drawn states. That failure remains explicit. Its later export was committed after pause, with zero outstanding steps and unchanged snapshot. No missing drawn state, held view or geometry is reconstructed here.

The export epoch was **seaTime 328.04104655763683**, solverTime **52.69999999999905**, offset **275.34104655763775**; it differs from the earlier drawn states. Each arm imported that same held transport state into the real canonical simulation. The SET1 export omits RATEH and NU, so those fields retained constructor defaults in the timed workload. All original peak/CFL/clock loops still ran, but this does not reproduce the native evolved viscosity/CFL distribution or internal F64 precision. Forty complete calls per arm advanced host solver time to 53.36666666666568.
