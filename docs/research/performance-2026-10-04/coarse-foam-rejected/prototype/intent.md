The source authority is commit `58ceb6a29617c00f93fb3b21eff3058d824319d5`; extract its archived source into this new scratch directory only after the hardware hold is released. The first candidate changes spatial coverage resolution only, at every original 60 Hz update and with the original `dt`.

## Grid and visual update

Group consecutive fine columns `[2c, min(2c+2,nx))` and rows `[4r, min(4r+4,nz))`. Use actual fine cell edges, summed widths and rectangle midpoints, not a uniform 4 m lattice. Thus offshore rows already wider than 4 m remain grouped rather than refined. A final one-column or one-to-three-row group retains its actual width/area; one-cell axes have constant clamped sampling. Coarse count is `ceil(nx/2)*ceil(nz/4)`, approximately N/8, not universally exactly N/8.

In one fine ascending scan, compute the exact original physical bore/source outputs and additionally accumulate each group's wet water volume, wet momentum and source-covered area rate. The physical rate expression and its assignment/list append operations retain the original arithmetic. For the visual velocity, use `sum(q*area)/sum(h*area)` over wet fine cells; for coverage forcing, use `sum(rate*area)/groupArea`. Clear an entirely dry group. Coverage fractions are per full group area, bounded [0,1]; mixed wet/dry coarse groups and shoreline dilution are explicit visual approximations, with fine snapshot wet gating retained. Neither accumulated flow nor visual coverage writes physical h/q/air.

After window synchronization and source/flow aggregation, advect coarse dense/residual semi-Lagrangian at the unchanged `dt`, using the nonuniform coarse centres. Apply the existing decay, lace share, trace threshold and cap equations once per coarse cell. The original fine path is kept as the oracle, including its shared-stencil behavior. Do not run a 2dt lookup, skip source measurement, change particle budgets, or infer breaking membership from only positive sources.

Coarse coverage does not produce/consume a fine `AdvectionStencil`. `aerateBores(dt)` uses the exact retained breaking prefix and dissipation, including wet positive-strength cells whose bore power is zero. `AerationField.update(dt)` uses its existing independent fine departure path, unchanged, after all original bore/plunge/stir calls. The air fallback must be bit-identical to canonical shared-stencil air; existing shared-stencil tests support that contract, but the candidate parity test will verify it again on the relevant sequence.

## Splash, movement, state and snapshots

* Splash: reject the same open-edge x first, synchronize the coverage window, map the original fine landing cell to its group, then add `volume/(groupArea*SPLASH_DEPTH)`. Unsaturated area-integrated increment equals `volume/SPLASH_DEPTH`; caps and clearing impose the same intentional loss semantics. Aeration plunge volume/energy and lip/solver callbacks remain untouched.
* Window movement: do not round an odd fine-column shift to a coarse column. Remap piecewise-constant coverage by exact old/new rectangle overlap along x, using preallocated next buffers and actual partial edge widths. Newly entered area is zero. Fully overlapping represented area is conserved before cap/decay, with expected out-of-window loss. Synchronize before either splash or update to prevent a new splash shifting twice. Even shifts may use a proven equivalent fast path; full-width displacement clears coverage. No solver movement or boundary logic changes.
* Export/import: retain ordinary physical state arrays/counters/order. Add an optional coverage-layout header to `SurfZoneState` and its encoder (group factors, coarse dimensions and represented x origin). Same-layout direct round-trip must restore dense/residual bit-exact and establish matching window origin. Explicitly accept unmarked canonical fine coverage by area-weighted downsampling only; reject unknown factors/dimensions/origins instead of guessing. New coarse state must never masquerade as fine merely because its array length happens to match in a tiny domain. Existing Float32 network quantization remains unchanged; test its own round-trip separately from direct Float64 transfer. No attempt to repair unrelated original physical-window handover semantics.
* Snapshot: add a cached coarse-coordinate lookup keyed by both render layout and coverage window origin. In the existing fused snapshot loop, replace only surface channel 1's foam interpolation. Leave height/depth/bed weights and expression order, flow calculations, void fractions/plume depth and dry gating exactly intact. Do not materialize an upsampled fine foam array or split the fused snapshot into repeated physical passes. The plain `writeUniformSurface`/snapshot routes must agree.

## Gates before a larger implementation or quality trial

1. Pure grid tests: uniform and stretched dz, non-multiple nx/nz, one-cell axes, no offshore refinement, actual group areas and finite clamped lookups; dry/mixed groups and bounded coverage.
2. Physical differential test against archived 58ceb: replay a short supplied h/q/bed/breaking sequence at original 1/60 dt, without solver stepping. Include wet/dry crossings, zero-power positive breaking, moving flow, lip-like splash/plunge and positive/negative odd/even window shifts. Compare source arrays, active source/breaking prefixes, counts, indexed dissipation and original inactive-slot semantics bit-for-bit. Verify no writes to h/q/bed/coordinates or breaking input.
3. Run identical bore/plunge/stir calls and canonical shared-stencil vs candidate existing-fallback air evolution. Compare full air/depth/turbulence arrays bit-for-bit every step, then compare board-facing water/air samples. With fixed RNGs and unchanged fine source/area, compare one bounded BubbleCloud/SprayCloud birth/update sequence and RNG visitation; coarse visual coverage is intentionally excluded from old-data equality.
4. Splashes/window: unsaturated area-volume dose, saturation bounds, open-edge rejection, retained-area/centroid behavior for odd shifts and partial final cells, repeated splash/update synchronization. Piecewise remap is approximate advection but its represented overlap conservation must be asserted.
5. State and snapshot: direct same-layout restore/next update, fine-state downsample, encoded layout retention, malformed-layout rejection; exact physical export arrays/counters; bit-identical surface channel 0, flow, aeration and bed from fused snapshots at changed render/windows. Compare coarse foam against its independent sampler, not against old foam bits.

Only after root approves the architecture and releases hardware: implement in scratch, run focused CPU gates/typecheck, record an owned-file patch/source manifest. A later bounded rotating-order measurement must include **foam measurement + coverage + air sources + air advection + fused snapshot**, using a held supplied water state and no solver/GPU. Report complete-path time and allocation/work counts, not an assumed 8x speedup. Fine source/air scans stay; loss of shared foam departure means air recomputes its fine lookup, and grouping adds accumulations. Memory/work reduction of coverage alone does not prove a whole-step win. Fixed-state and moving visual quality/FPS require separately reviewed hardware trials; this intent grants none.
