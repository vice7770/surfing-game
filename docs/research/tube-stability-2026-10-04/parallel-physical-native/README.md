This standard-library verifier hashes every payload and relative shared-sheet reference, losslessly decodes gzip records, and applies four archived patch sets with exact context and no fuzz to the retained preimages. It checks the original final owner states and capture inventories. It does not execute archived helper code, launch resources, build, or rerun numerical/model tests. Add `--originals` only while the original scratch inputs still exist to rehash those mapped originals and recorded source/build/helper pin groups. Original records retain their absolute scratch paths and bytes; they were not rewritten for portability. Only the touched patch preimages/postimages are self-contained with the neighboring shared-sheet archive. Entire source trees, dependency bytes and all 49 built asset payloads are not stored here, so full future source reconstruction, test replay or runtime rebuild is **not claimed**. Successful archive verification means preserved artifacts and exact local patches; it does not mean an accepted tube.
