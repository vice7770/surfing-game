This isolated candidate corrects C's once-only column pace and extrusion width. A fresh `crestMotion` at the original solver source cell supplies physical `direction.z`; the same historical smoothed normal speed, wave fallback and normal-speed clamps remain in `pace()`. Pace is `c_n / max(0.5, physicalZ)`. C drawing/contact/throw rays stay `[0,1]`. If a fresh measurement is unavailable, the immediate pre-new-throw crest tangent supplies an explicitly recorded geometric normal approximation. No direction-retention or smoothing state was added. All new throws finalize after their source-cell measurements. Already paced points keep their pace through relabels.

C slice width is the half-sum of neighboring X differences. Sigma clocks, end fades, profile controls and the RAW expression remain unchanged. This fixes the orientation Jacobian for uniform constant-X sections. The existing local area-times-width formula and centered end footprints remain approximations for varying profiles, water, end fades and ages; the correction does not establish exact whole-mesh volume integration.
