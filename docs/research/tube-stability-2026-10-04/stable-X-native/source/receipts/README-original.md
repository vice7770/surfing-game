This source candidate removes whole-front sigma-grid rephasing from the controlled carrier-release stress. It is prepared for an independent build/native evaluation; it has no native, pixel, mouth, body, FPS or production acceptance. The repository and every parent input remain unchanged.

Raw knots have priority over optional stations at exact X/sigma word collisions; distinct mandatory knots are never approximately merged. Every actual stored C column pair proves positive X and sigma advance. Default ray preparation and RAW arithmetic/output keys retain their parent paths.

The global budget decision, raw-dead-before-budget clamp guard, loft lifetime, physical funding, air, immutable jet values, carrier history, overlap policy and final run seal are preserved. Mandatory knots can exhaust the hard geometry cap earlier: the candidate retains a sealed prefix, never skips an interior live raw knot to reconnect, and reports truncation/omitted fronts. Raw F32 X/Z/sigma/age/H/D must be finite, H/D positive, and X/sigma strictly increasing within each front; NaN pace retains its existing meaning.
