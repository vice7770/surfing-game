## Public history and native helper contract

The authoritative machine-readable contract is `public-history-contract.json`. The exported point field is optional `carrierSupport`, present on paced C points and absent on unpaced ones. It is **dynamic evidence**, never an immutable identity fingerprint.

| Field | Meaning |
| --- | --- |
| `policy` | Exact literal `bounded-C-incident-support/v1` |
| `atTau` | Finite source tau at refresh; exact equality to current point tau qualifies retained pace |
| `solverTime` | Finite source solver epoch at refresh; held/imported state can precede the exported solver epoch |
| `ownPocketAlive` | Boolean `point.tau < unchanged point.jetUntil` |
| `retainedForGeometry` | Boolean `!ownPocketAlive && incidents.some(potentiallyLive)` |
| `geometricPaceActive` | Boolean `ownPocketAlive || retainedForGeometry` |
| `state` | `own-pocket`, `incident-support`, or `released` |
| `incidents` | Current adjacent same-front increasing-X dependencies; held points have none |

Each incident has exactly `otherId`, `front`, `boundSeconds`, `minimumPacketAge`, `potentiallyLive`, `maxScale`, `maxAuthoredTD`, `partitions`. IDs/fronts are nonnegative integers. Bound/scale/authoredTD are finite positive; partitions is a positive integer. **`minimumPacketAge` is finite but may be negative** when the younger neighbor is pre-throw. `potentiallyLive` is exactly `minimumPacketAge < boundSeconds`.

The shared pace predicate is the old own gate (`jetPace` and `jetUntil` defined and `tau < jetUntil`) OR exact history policy, `history.atTau === point.tau`, true `history.geometricPaceActive`, and defined `jetPace`/`jetBase`.
