# Carrier release stress: sampling and end-seal audit

Read-only narrow follow-up using the completed independent stress harness and the frozen carrier source. No source edits, tests/reruns, build, native/browser/resource/probe/Git actions; only this new notes folder written. Prior source pins and validation were not re-reviewed. Report arithmetic here operates on existing saved observations only.

## Judgment

Treat this as a **bounded native-observation caveat for the frozen carrier candidate**, not a blocker or a reason to add an untested sampling fix before its finite capture. The evidence establishes a separate source-level sampling dependency worth a future isolated candidate: dead raw geometry still affects the distribution/phase of surviving loft slices and the location of the discrete end seal. It does not demonstrate raster visibility, an acceptable threshold, or a safe one-line fix. It is not a 15ms change in the surviving raw source clocks.

The stress is explicitly synthetic except for the two measured reacquisition distances. It runs one tracker→real clock fitter→crash→loft update for each distance with uniform foot dimensions and constructed aligned bases/linear peel times; it is not native replay or a temporal whole-release trajectory. Five tests enforce contract/positive-roof gates, not numerical continuity tolerances. Both arms have 43 rows and matching counts/flags; corresponding rows still have different sample positions, clocks and weights.

1. Released points0–3 reacquire solver Z, while expired point4 remains paced because its incident with point5 is still alive. Tracker link uses Euclidean distance for sigma (`BreakingFront.ts:561–565`), and final crash placement remeasures arc after pacing (`SweptCrash.ts:238–240,550–560`). At the dead X7→retained X9 segment, +2.808105469m Z changes its arc length from2m to3.447529017m, adding1.447529017m to downstream raw sigma while surviving raw X/Z remain essentially identical. +2.634963989m adds1.308025880m. Adjacent live sigma differences barely change; absolute sigmas and total raw-front span do.
2. Loft front bounds include the full raw component (`sweptLoft.ts:402–413`), even faded early raw points. `baseSlices:418–425` spans first−extension to last+extension, computes ceil(span/spacing)+1, and divides the whole span evenly. On saved source-double sigma, baseline span31.002200910m produces64 base samples at0.492098427m; newer distance gives32.310226804m/66 at0.497080412m; older distance gives32.449729911m/66 at0.499226614m. Actual packet uses F32 sigma, with insignificant differences from these predicted figures. This global redistribution rephases surviving slices in X despite invariant live raw endpoints. Refinements may add midpoints (`:454–465`) but do not insert every raw parameter knot.
3. Each selected sigma samples piecewise-linear raw X/Z/tau/H/D (`:510–519`). Faded samples are then removed (`:547–561,618–621`), leaving the first surviving grid row as a new cut. Cut sealing uses distance from *that grid row*, not the continuous raw/provider retirement boundary (`:961–990`). Thus this cut and its taper anchor shift when dead raw geometry rephases the grid.
4. The seal smoothstep multiplies sliceWeight/lift/sheet/throat and moves Y toward underlying water (`:979–995`). Drawing and contact share it. It does not alter slice tau. First row is forced to weight0. It is a real existing geometric closure rule, not an added shader/camera artifact.

## What a separate sampling candidate would need

The source justifies considering C sampling whose phase is tied to stable fixed-X/source stations or independently sampled surviving supports, rather than the full raw sigma span; the C policy already requires increasingX and fixes drawing rays shoreward. Raw parameter knots should be represented if mesh-interpolated age must preserve the kink. A cut taper anchored to a continuously located provider retirement boundary would address the discrete cut-anchor response. These are candidate directions, not a proven safe implementation.

Only adding raw X11 as a row can improve the sampled clock kink but cannot by itself remove grid-dependent end-seal Y differences. Only changing the taper anchor cannot repair the piecewise raw-age knot approximation. Dropping sealRuns could leave an unclosed raised boundary/mask mismatch; pinning slice ages/Y or muting them would alter authored geometry/contact semantics. Neither is justified by this report.

Any new sampling implementation needs bounded tests for draw/contact equality, RAW preservation, provider/clamped/F32 domains, budget/extension/cut/overlap masks and coverage. Keep it separate from this frozen carrier correction. For the finite native capture, record first certificate-release state and nearby current joined positive-weight phase2 geometry, actual camera pose and original raster appearance; keep the existing stop on join loss. The current data supports a localized sampling caveat and an independently scoped future improvement, not adoption or a shortcut around the visibility gates.
