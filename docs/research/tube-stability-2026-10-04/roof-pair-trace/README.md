Stored phase-then-size and size-then-phase decompositions describe hypothetical original-library queries; no smoothing prototype is implemented.

Full unused source/dependency/compiler/dist/typed bodies and all PNG payloads are omitted. Original camera/PNG references are metadata only. There is no full runtime replay closure, native recapture, user-video reproduction, fin-cause attribution, tube-quality pass or runtime adoption claim.
