## Isolated source port

Source is under source/, with accepted root source copied and SHA-checked against source-baseline.json and retained in baseline-src/. Raw decode/assets remain unchanged. Direct new ProfileLibrary(cases) retains authored semantics; new ProfileLibrary(cases,{geometry:'bounded-C'}) explicitly opts in. The normal asset factory opts in only when all decoded ids belong to the eight shipped cases. General fixtures/custom libraries remain raw unless explicitly opted in; eligible provider domain failures throw, never silently fall back.

Parameters blend before construction. Every analytic hold mode uses the same age and contour. Raw carrier/outside vertices and anchor vectors sample min(age, blended authoredTD); afterward the carrier settles while analytic roof continues through actual impact and retirement. This is an explicit query integration policy, not a per-frame geometry exception. Stable clocks come from the final authoredTD carrier. Fully formed clearSeconds=.4 authoredTD describes formation and does not freeze geometry. AuthoredTD is sealing start; actual impact is later. profileTimes and profileAt publish actual impact/collapse timing, with authored sealing separately in metadata.

profileAt/pointAt/FrameBlend.analyticProfile share final metric contour; analytic metadata is ND with explicit lengthScale/timeScale. Tip boundary velocity derives the full query, including carrier/parameter transport. Advective fluid speed sqrt(2H) and roof direction remain a separate explicit game approximation. Query/event caches are bounded64/128; final-carrier event reused beforeTD because its cap datum is unused by preTD construction. This optimization does not change frozen preTD geometry; it makes one actual lifecycle clock authoritative. crestReachBounds includes preserved raw reach plus proven conservative analytic cap/root envelope and F32 blend margin.
