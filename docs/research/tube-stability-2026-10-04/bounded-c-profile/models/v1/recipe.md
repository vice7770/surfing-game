## Low-dimensional leaf, phases and limits

W=Toe.x-A.x, H=A.y-Toe.y must be positive, both tangent X components forward, TD positive. Ordinary A->Toe cubic handles are chord/3 capped at W/(3*tangentX); split exactly at .5 gives K0,d0,half handles ha0/he0/ht0. Base thickness B=min(.06H,W/16,.1 min((.85W)^2/(.88H),(.88H)^2/(.85W))). Formation g=smoothstep(tau/(.4TD)). Mature lip reference L=(Toe.x-2B-.02W,Toe.y+.12H-.18H*seal). K=(1-g)K0+gL. Endpoint direction rotates from d0 to downward vertical with g. Handles interpolate ordinary split magnitudes to quarter-oval kappa=4/3 tan(pi/8) times leaf width/height. If combined forward-X handle advance exceeds .85 leaf width, scale both magnitudes by that common ratio. This is a global geometric budget, not a coefficient fit.

TD begins sealing: seal=smoothstep((tau-TD)/(.3TD)). Solve actual cap minimum-to-Toe height zero with32 bisections in seal, then invert smoothstep32 bisections to determine impact tau. After impact remaining h=1-smoothstep((tau-impact)/(.3TD)); thickness=B*h^2. The cap rests on one shared F32 datum C=(F32(impactCapX), exactToeY). Roof endpoint direction rotates continuously from down at h1 to right at h0. Solve K from C+vertical half thickness+actual last facet inward half-thickness normal with16 fixed iterations. Thus the retired leaf ends horizontally on the SAME floor direction; fluid flow is not stationary merely because the boundary rests there.

Ordinary and retired zero-loop states are exact algebraic limits:61..106 coincide with K;107..112 sample the common tail. Ordinary tail uses he0/ht0 split handles, direction d0; positive formation uses hTailStart=(1-g)*he0+g*tailChord/3, hTailEnd=(1-g)*ht0+g*tailChord/3 and the same forward-X caps. Retired tail uses horizontal start and tailChord/3 end; positive retirement uses these same controls. No separate convention at zero thickness.

## Precision state

ULP=F32 spacing at max absolute A/Toe coordinate. Characteristic loop scale before impact=min(gW,gH), after=min(hW,h^2H). If thickness is zero or loop scale<=64ULP, publish collapsed topology with no sheet/void/coverage from the exact corresponding zero limit. Record collapse spatial bound max(gW,gH) or max(hW,hH); if a nonzero precision collapse exceeds .001*max(W,H), explicit failure. For resolved loops require thickness=max(requested,8ULP), record increase. This changes sheet boundary by ULP scale only; it does not raise the desired void or create air. Any failure of offset/root feasibility after this floor remains a failure. All representability failures and switch displacement are retained; quantization is not a claim of differentiability.
