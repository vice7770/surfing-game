# Two-branch shared cavity draft

This is a source-only structural experiment, not an accepted tube, contact fix, or performance result. The 588 inputs are a literal copy of the frozen cap-prefix-v2 provider, with changes only to `boundedCProfile.ts` and its existing `sharedUpperRoot.test.ts`. No rejected shader or longitudinal compliance runtime is inherited.

The previous single cap-to-toe cubic cannot meet the retained horizontal-toe floor datum. This draft retains that datum and uses two branches. In the resolved shared-provider path, the returning cavity is cap68 → the existing minimum-X join88 → the existing plateau start102. Cap60..68, join88, plateau102..106 and tail107..112 remain exact construction points. The collapsed connector, authored roof/cap controls, thickness parameter, clocks, crest/toe anchors, lifecycle, and original unpaired v4 construction remain unchanged. RAW remains its original separate route.

The branch controls are:

    upper = [C, C + hc*(-last), B + hu*(0,1), B]
    lower = [B, B + hl*(0,-1), F - hf*pv, F]

Here C is retained cap68, B is retained join88 from the bounded root, F is retained plateau start102, `last` is the actual terminal roof facet direction and `pv` is the existing floor direction. `hc` is bounded by the actual terminal offset-facet length, upper chord/3 and upper X width/(-3*ux). `hu` is the minimum of the existing KAPPA*rootRadius and both chord/3 values. `hl=hu*14/20`, so the derivatives divided by the 20 upper and 14 lower material-index intervals agree at B. `hf` is bounded by lower chord/3 and lower X width/(3*pv.x). All handles must be positive; a failure is explicit, with no RAW fallback, vertex clamp, hidden domain removal or retry.

These bounds order the upper control X values Cx ≥ C1x ≥ Bx = C2x and the lower control X values Bx = C1x ≤ C2x ≤ Fx. Thus the double-precision cubics have one minimum-X join, without an internal X return detour. The upper branch lies in the old join-to-cap X interval, which the shared root already constrained to the complete outer roof domain. Analytic cap and floor tangent directions are preserved, and the two branch derivatives agree at B under material-index parameterization. Float32 quantization and sampled facet tangents still need actual checks; this is not a claim that the triangle mesh is everywhere continuously differentiable.

The old root calculation still supplies its join and handle scale. Its circle/vertical/face certificate does **not** certify the new Bezier hulls. The rootRadius/rootVerticalLeg metadata remain that old construction scale/depth, not the curvature or vertical length of the new spline. An `innerContour: two-branch-cavity/v1` marker identifies the resolved draft. Retaining metadata T alone does not prove actual material thickness. Carrier clearance, noncrossing, positive paired separation, precision-switch envelope continuity and all existing legal thin/retirement/carrier-prefix domains remain unproven until root runs their numerical gates. The retained join means this draft does not independently widen the minimum-X mouth; its appearance hypothesis is a coherent cavity contour with fewer internal turns.
