# Unapplied conservative outside-witness broadphase

No optimization is installed in this recipe. V3's measured classifier work was only~5.7s, so evidence does not currently justify spending acceptance risk to optimize it. The following is a mathematical source-only proposal for future review after V4 phase timings.

For a current active indexed component, compute bounds only from the actual vertices referenced by its active triangle indices. Every point of each closed triangle is a convex combination of its three vertices, so its x/z coordinates lie within their minima/maxima, and every triangle lies within the union/component AABB. With finite bounds, the exact strict comparisons `x+r<minX || x-r>maxX || z+r<minZ || z-r>maxZ` prove the entire equivalent-volume sphere AABB is separated from that component's triangles. If this holds for every active component, the existing sphere scan's per-triangle AABB test would skip every triangle. It can return the same existing no-near-candidate result: clear=true, intersectsOrTouches=false, checkedNearTriangles=0, minimumNearCandidateDistance=null, lowerBoundIfNoNearCandidate=radius, nearestTriangle=null. Do not use `<=`; touching is not separated. For radius0 points, strict x/z separation also proves zero covering vertical crossings for that component, allowing the existing crossing function to return its exact empty list (it already uses component bounds).

This proof applies to the actual discrete sphere/point witness and active indexed triangles only. It does not enclose the skinned body, limb segments, board sweep, displaced shader surface, or connected air volume. A witness outside a cavity may remain above the ordinary face and inside the full component AABB; its `classification==='outside'` is not a separation predicate. A centre outside an AABB with a radius crossing the boundary also cannot use the skip. Bounds must be recomputed from every current generation's indexed active words, not cached by topology alone; positions move while indices stay equal. Nonfinite or unavailable bounds must retain the original scan or fail, never certify clearance.

A component-level sphere rejection can reduce scans only for components satisfying the strict radius-expanded separation; it preserves all original triangle tests for intersecting AABBs. A global AABB may be weaker but simpler. Any implementation needs source and meaningful exact-result parity checks covering outside, touching, large radii, degenerate triangles, moving vertices with unchanged topology and disconnected components. It must preserve the existing candidate output/order, first-front authority, radius-footprint ordinary-water bound, and full21-witness union acceptance. The existing ordinary-water fallback still requires an undefined drawn answer and actual zero covering candidates; sphere separation alone is not permission to change that water authority.
