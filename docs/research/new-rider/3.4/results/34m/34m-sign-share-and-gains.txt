# Step 3.4m. The `?plantFloor=4.5|5|6` switch, built, and the primary metric measured on step 3.4l's own arms.
#
# THE SWITCH. `labAt(speed, floor)` takes the lowest row of `PLANT_SPEEDS` the lookup may land on. Shipped it is the
# table's own first speed, 4, so every design at or below 4 m/s reads row '4'. `DesignWeights.plantFloor` carries it
# through `scheduledDesign` -> `plantAt` -> `labAt`; `AttachedRiderOptions.plantFloor` and the `?plantFloor` dev
# switch reach the same weights route. Nothing but the table lookup moves: `speed` still enters the kinematic rows,
# the rail correction, the board's inertia and the heave plant at its true value.
#
# THE RIG. `3.3/plant.ts` with `FLOOR=4.5|5|6` (the probe's own switch for it) and ONE new counterfactual column
# trio -- `kModelFloor`/`yModelFloor`/`nModelFloor`, the same three loads from the SAME tick state with the table
# read off a 4.5 m/s floor -- computed on every ride whatever `FLOOR` says. That trio is what lets the question
# "does the row change the sign" be answered on one trajectory's own ticks instead of across two rides that have
# diverged.
#
# THE DEFAULT, MEASURED AND NOT ASSERTED.
#   model: `labAt`/`plantAt` with no floor against the floor at 4 -- 168 comparisons, identical bit for bit;
#          the whole gain schedule (17 speeds x 3 depths x 6 rails = 306 cells x 767 numbers a cell) identical.
#   ride:  `f73-l` with the switch unset reproduces step 3.4i's and step 3.4l's published arm EXACTLY --
#          18 of 18 fell, 0.617-2.533 s, median 1.450 s.
#
# ARMS. Step 3.4l's own, unchanged: `RIDER=new FELT=deck BODY=two`, AHEAD 0.75, SIDE -45, 9 s a run, the stance
# held, the stick never touched. `f73-l` = FACE 1.4,7.32,5.7 ENTRIES 1..6 x 3 stances (18 runs); `s16-l` =
# FACE 1.4,16,5.7, the same entries (18); `s16-g` = FACE 1.4,16,5.7, the default eight relative entries (24).
#
# CUTS. Step 3.4l's own (`../34l/34l-read-cuts.py`), so the before/after is read the same way:
#   A = live, speedClamped == 1 (speedUsed outside the SHIPPED table's 4-12 m/s), |roll| <= 25 deg
#   B = A and speed <= 1.6 m/s -- the owner's own cell, and THIN (12-27 ticks a stance)
#   C = live, speedClamped == 0, |roll| <= 25 -- the honest band, the control that must not move
# `speedClamped` keeps the SHIPPED 4-12 definition in both arms, so "clamped" names the same band of speeds on
# either side of the switch. The sign share is over live ticks with both forces non-zero, as 3.4l took it.
# Every count is ticks, per stance, NEVER pooled. The rides are NOT the same ticks across arms -- the switch
