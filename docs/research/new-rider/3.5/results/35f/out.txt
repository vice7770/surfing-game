## §3 The stick's own authority, per latch state — the stick never touched against the stick hard over

  The measured form of "unresponsive". For every face, stance and entry the reader pairs the `-s0` run (the stick
  NEVER TOUCHED) with the `-s1` run (the stick HARD OVER): the same water, the same placement, the same stance,
  the same entry — one input changed. It then counts **column-values**, as step 3.5a's flat-control result did:
  every numeric column of the dump that is not a label, on every frame both runs are live for, compared pair to
  pair, split by the latch state the frame is in. `mism(1e-9)` is how many of those values differ at all.

  `virgin` = off the plane and NEITHER run has planed yet (the honest off-plane population); `after` = off the
