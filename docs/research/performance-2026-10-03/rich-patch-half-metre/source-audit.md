# Patch .25 → .5 source audit (read-only)

No build, solver replay, browser, GPU probe or production edit. Sources reviewed in the canonical checkout; only this temporary note was written.

## Nesting: yes between patch meshes, no for every supported source grid

`src/scene/water/richPatch.ts:5–8,65–104` fixes the actual local square at 96m and builds 384 versus 192 intervals. Candidate local coordinate `-48+i*.5` equals old coordinate `-48+(2*i)*.25` exactly; these are exactly representable Float32 values. The four top rims and their skirt-copy coordinates are likewise every other old rim vertex. This holds for all ordinary clamped/narrowed rectangles because both densities receive the same unchanged placement and scale: width/96, depth/96, y=1 (`WaterSurface.ts:529–537`). The actual world patch steps are width/192 and depth/192, at most .5m. An arbitrary generic `createPatchGeometry(size,spacing)` call with rounded, non-divisible size does not have the same theorem; production uses fixed96.

Shared patch vertices retain the same model/sample coordinate and shader displacement for identical uniforms and ordinary transforms (`richWaterGlsl.ts:50–59,70–74`). Both top and bottom copies sample the same cubic height; bottom is exactly .3m lower in the ordinary model. The two-density transform/shared-sample equality survives a rectangle width/depth that is not a quarter-metre multiple. It does not claim equality to separately constructed coarse mesh vertices, shader interpolation, depth or pixels.

`patchRect` snaps first and then clamps (`richPatch.ts:45–57`). An upper clamp can undo source-node snapping when `extent-96` is not an integer multiple of grid.spacing. For full96m axes, candidate step is .5m. All source/coarse nodes within that axis lie on patch vertices in ideal arithmetic only when the phase `(gridOrigin-rectStart)/.5` and ratio `grid.spacing/.5` are integers. Default spacing1/2 meets these conditions, including the upper clamp; spacing.25/.75 generally does not. The old .25m comment “include every node” is not a universal public-grid contract either.

For a narrowed axis with M=nx-1 intervals, width=M*grid.spacing and rect starts at grid origin. A source node k maps to candidate index `192*k/M`; every node is included iff M divides192 (old mesh: M divides384). Concrete supported counterexample: nx129, spacing.5, extent64m. Old includes every source node because384/128=3; new misses alternating source nodes because192/128=1.5. Existing40m/30m narrow-grid test proves containment only, not node inclusion. Source/coarse positions also undergo their own Float32 geometry/matrix arithmetic (`WaterSurface.ts:687–695`); ideal-grid membership is not a bit-exact coarse-vs-patch shader-coordinate proof.

## The triangles and rim curtain change between common samples

Both densities use the same diagonal `a,c,b / b,c,d` (`richPatch.ts:76–82`). In horizontal projection each candidate triangle is a union of old triangles, but the displaced old triangles generally do not share its plane: removed .25m samples need not lie on the .5m chord. The same applies to each rim curtain. Per-pixel cubic normals remain unchanged functions; geometric silhouettes, interpolated depth/foam/air/flow and skirt visibility can change. Nesting alone cannot accept coverage or depth.

## What the .3m skirt and .5m overlap can actually certify

Let P be the candidate patch's piecewise-linear rendered top and C the coarse rendered heightfield, not the continuously sampled cubic H. At the outer patch rim, the curtain spans `[P-.3,P]`. A source-backed **geometric rim closure** criterion is `P-.3+epsilon <= C <= P-epsilon` wherever that curtain must hide the coarse join, with equality handled conservatively; epsilon covers the actual floating-point transformation/displacement error. Coarse must still survive its own bed/mask/discard there, and the curtain must face/cover the tested view (`richPatch.ts:26–29`). This criterion can be tested exactly in real arithmetic at the union of patch-rim sample points and coarse triangle/edge intersections: C-P is linear between those breakpoints. This is narrower than unchanged shaded/depth coverage.

The coarse discard boundary is .5m inside the patch, independent of tessellation. That gives at least one candidate cell of nominal horizontal overlap, but it is not a bound on vertical separation or its projected effect. A complete view-specific concealment claim must additionally bound relative surface heights/slopes throughout that band and require its projected overlap to exceed their screen-edge separation. Grazing views make a vertical separation's horizontal projection arbitrarily large; a fixed .5m band alone cannot guarantee all-view concealment. Coarse-above-patch separation also has the wrong sign for the downward curtain. Below-water views are further constrained by the existing back-face curtain discard. No repeated MSAA/culling argument is needed for this basic geometric limit.

A finite state-dependent curvature bound is available in principle for the ordinary swept Padang path. Both meshes sample the same Catmull-Rom H (`cubicSurface.ts:40–68`); `SnapshotSurfZone.writeTubes` returns0 for swept spots (`SurfZoneHost.ts:172–173`), so H is not the min/carved legacy tube field. If the Hessian operator norm is bounded by K over all intersected cubic cells, right-triangle interpolation obeys `|I(H)-H| <= K*(width^2+depth^2)/8`. The default2m coarse and at-most.5m candidate then have `|C-P| <= 1.0625*K + numerical epsilon` (metres). Nested patch triangulations also give `|P_new-P_old| <= .0625*K + epsilon`; maxima occur at old triangle vertices, where old equals H. Along a full-size, default-grid-aligned rim, the sharper 1D chord difference bound is `|C-P| <= K_t*2^2/8 = .5*K_t` because coarse knots are retained by the patch. None supplies the required sign, camera condition or arithmetic allowance by itself.

K could be bounded from actual cubic coefficients/raw finite source nodes (piecewise second derivatives), or bypassed with a direct rendered-triangle comparison on a held state. Current `SurfaceSource` permits arbitrary heights and publishes no Hessian/curvature/seam bound. Scaling valid quadratic node data makes C-P arbitrarily large, including either sign. Therefore the unchanged .3/.5 constants have no universal source-contract guarantee on arbitrary grids/states. Retain this limit label for the trial: **default and selected close-view quality evidence**, not all-grid seam parity. Actual captured rendered geometry/skirt and normal images are required for acceptance; the source audit supplies no FPS or visual result.
