# Set MVP run outcomes

Status: RESOLVED  
Type: wayfinder:grilling  
Blocked by: none

## Question

How does a run conclude, and what can the player do afterward?

## Resolution

A run ends in a clear ride-complete, missed-wave, or wipeout state. The player can replay the same seed/settings or request a New Wave with a different seed. The transition decisions are recorded in [Set run transition and outcome criteria](set-run-criteria.md); detailed attempt/failure recording remains future scope.
