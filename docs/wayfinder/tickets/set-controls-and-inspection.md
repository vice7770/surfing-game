# Set MVP interaction and inspection tools

Status: RESOLVED  
Type: wayfinder:grilling  
Blocked by: none

## Question

Which controls, camera views, and tuning tools are required to test the core wave mechanics?

## Resolution

Use keyboard controls: hold a paddle key to build speed before wave arrival; trigger Get Up with Enter or an on-screen button only when the timed pop-up window is available; use directional input for steering and balance during a ride. The wave/board interaction is the primary visual cue, without a persistent tutorial prompt. The default camera is third person and keeps surfer and approaching wave visible. Provide a diagnostic wave view and an in-game tuning panel with wave height, period, wave speed, a board response setting, and paddle strength. Include these settings in replay conditions. Exact mappings, units, defaults, and ranges are specified by [Set control mappings and tuning ranges](set-controls-and-tuning.md).
